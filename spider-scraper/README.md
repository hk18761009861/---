# 🕷 蜘蛛爬虫

一边真正抓取网页数据，一边看一只程序化蜘蛛在抓到的文字上爬：它爬过的每一段内容都会被扫描、收割，变成数据包飞进结果面板，最后可以导出 JSON / CSV。

特效灵感来自 [@rybinfx](https://x.com/rybinfx) 和 [cyohei9907/web-crawlers](https://github.com/cyohei9907/web-crawlers)，代码为独立实现。

## 运行

需要 Python 3（只用标准库，不用 `pip install`）。

- **Windows**：双击 `启动.bat`
- **Mac / Linux**：

  ```bash
  cd spider-scraper
  python3 server.py          # 自动打开 http://localhost:8765
  ```

在顶栏输入网址，点「放出蜘蛛」。

| 设置 | 作用 |
|---|---|
| 页数 | 读完第一页后，沿页面里的同站链接继续爬，最多爬几页 |
| 链接含 | 只跟随网址里包含这段文字的链接，例如 `/article/` |
| 速度 | 蜘蛛爬行速度（只影响动画，不影响抓取） |
| 跳过动画 | 不等蜘蛛，立刻收完所有数据 |

在文字区移动鼠标，蜘蛛会追着光标；点击某处它会爬过去；`空格` 暂停，`F` 切换镜头跟随。

## 能抓到什么

每个页面会提取：标题、描述、各级小标题、段落、列表、引用、代码块、表格（按行）、图片（地址 + 说明）、链接（文字 + 地址）。

- **导出 CSV**：每条数据一行，表格按行拆开。文件带 BOM，用 Excel 打开中文不乱码。
- **导出 JSON**：按页面分组的完整结构。

## 特效

- 8 条腿加 2 根触肢，两段式 IK，四足交替步态；脚真的抓在文字上，排版跳动时会松脚
- 踩到的词会变异：描边、锁定框、高亮、等宽放大、旋转、错切、RGB 分色、发光、波浪线、闪烁，或先变成乱码再逐字解码
- 文字拉伸成蛛丝色条，向远处的词射出下垂的蛛丝，漂移的残影，落脚波纹和火花，小腿扫过的文字也会被感染
- 收割：射出收割丝，内容块被扫描，数据包沿弧线飞进右侧面板，腹部的数据核心亮一下

## 限制与规矩

- 遵守目标网站的 `robots.txt`，每次请求间隔约 1 秒。
- 只抓服务器直接返回的 HTML。完全靠 JavaScript 渲染的网站（很多单页应用）能抓到的内容很少；需要登录的页面抓不到。
- 默认不抓本机和内网地址。要抓自己内网的页面，启动前设置环境变量 `SPIDER_ALLOW_LOCAL=1`。
- 请只抓取公开、允许抓取的内容，并遵守目标网站的使用条款。

## 文件

| 文件 | 作用 |
|---|---|
| `server.py` | 本地服务：提供页面，并在 `/api/crawl?url=` 抓取、解析网页 |
| `spider.js` | 蜘蛛引擎（运动、IK、步态、变异、蛛丝、收割） |
| `app.js` | 页面排版、多页队列、结果面板、导出 |
| `style.css` | 页面样式和所有文字变异样式 |
